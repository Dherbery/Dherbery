## ⭐ Featured Projects

### 🎯 Teepz — GPS Smartwatch Safety Platform for Schools
Lets Ghanaian schools onboard pupils onto GPS smartwatches, broadcast messages to a child's wrist, and bill for it, while guardians track their child and get SOS alerts. Four apps — school console, parent app, admin portal, and Android watch client — share one Django REST API with role-based access, and safety features run at the firmware layer so they survive the watch app crashing.

**Role:** Software Engineer Lead

**Tech Stack:** React 19 • TypeScript • TanStack Start • Expo (React Native) • Django REST Framework • PostgreSQL (Supabase) • Paystack • FCM


### 🏗️ ScanergyV2 — Building Inspection & Energy Assessment Platform
Built for Krontiva Africa, replacing paper forms and spreadsheets for Dutch/European energy auditors with one workflow — from Bluetooth laser measurement on-site to a certified NTA 8800 energy label. Includes offline sync for field work, AI-based anomaly detection, and a shared calculation engine across mobile and web.

**Role:** Software Engineer Lead

**Tech Stack:** Expo/React Native • Next.js • Supabase (Postgres, Realtime) • Python FastAPI • ESP32 firmware • Docker

🔗 Live Demo: Internal staging only (not public)


### 🍫 LBC Cocoa Purchasing Platform — Enterprise ERP
A full ERP for a Ghanaian Licensed Buying Company, covering cocoa purchasing from farmer registration through fund allocation, payment approval, and warehouse dispatch. Runs on a six-level jurisdiction hierarchy, state-machine-governed approval pipelines, and a real-time ops dashboard for national and district managers.

**Role:** Software Engineer Lead

**Tech Stack:** React 19 • TypeScript • Node.js/Express • Socket.IO • PostgreSQL/MySQL


### 💰 TaxFlago — Cross-Tax Early Warning System
Analyses a business's ledger and trial balance to catch tax exposure across VAT, PAYE, CIS, and Corporation Tax before HMRC does, using a 43-rule engine that only prices exposure the evidence can actually support. Every figure carries its formula and statutory basis, backed by a tamper-evident audit trail.

**Role:** Software Engineer Lead

**Tech Stack:** Next.js 16 • TypeScript • Drizzle ORM • Neon PostgreSQL • Better Auth • Paystack

🔗 Live Demo: [taxflago.com](https://taxflago.com/)


### 🎮 OHENEagency — Coin Top-Up Marketplace
A coin/credit marketplace for live-streaming apps (Poppo Live, Bigo-style), letting Ghanaian buyers top up in-app coins via MTN MoMo, Telecel Cash, AirtelTigo Money, or card instead of needing an international card. Full commercial loop from storefront to Paystack checkout to an admin fulfillment dashboard with Telegram order alerts.

**Role:** Software Engineer Lead

**Tech Stack:** Next.js 16 • TypeScript • Prisma • Supabase Postgres • Auth.js v5 • Paystack

🔗 Live Site: [oheneagency.com](https://oheneagency.com)
